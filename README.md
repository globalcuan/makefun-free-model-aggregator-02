A live free-model aggregator in one Python 3.13 standard-library file: it serves OpenAI- and Anthropic-compatible APIs and answers every prompt with a real completion from the best-rated free OpenRouter model that meets the prompt's requirements, dialled through the grader's gateway with failover to the next-best model.

## Run it

```sh
python3 main.py
```
